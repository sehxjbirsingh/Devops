      User Guide & Interactive API Manual

      📖 Quick Start (Plain English)

      1

      Track Issues & Tasks

      Go to Tasks & Issues, enter a title, pick an urgency level (P0 to P3), and click "Save Task". You can search tasks anytime.

      2

      Monitor Any Website

      In Website Monitor, type a URL (like your blog or API) and click "Add Monitor". Click "Ping" to see if it's online and how fast it answers.

      3

      Review Live Analytics

      Check the Live Analytics tab anytime to see live uptime, total requests served, and completion percentage.
